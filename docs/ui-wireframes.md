# TaskFlow — UI Wireframes

## 1. Overview

This document presents the wireframes for the primary TaskFlow user
interfaces.

The wireframes provide a visual representation of the application's screens
and interactions before implementation.

The designs focus on the core user journeys defined in the requirements and
user flows.

---

# 2. Authentication Screens

## 2.1 Registration

The registration screen allows a new user to create a TaskFlow account.

The screen includes:

- Full name
- Email address
- Password
- Confirm password
- Create Account button
- Login link for existing users

![TaskFlow Registration Wireframe](images/wireframes/registration.png)

## 2.2 Login

The login screen allows an existing user to access their TaskFlow account.

The screen includes:

- Email address
- Password
- Login button
- Sign up link for new users

![TaskFlow Login Wireframe](images/wireframes/login.png)

---

# 3. Dashboard

The dashboard provides the user with an overview of their tasks and their
overall task progress.

The screen includes:

- Task completion summary
- Task status overview
- Task list
- Search and filtering
- Create Task button
- Dashboard navigation
- Task navigation
- Category navigation
- Logout

![TaskFlow Dashboard Wireframe](images/wireframes/dashboard.png)

---

# 4. Empty Task State

The empty task state is displayed when the user has not created any tasks.

The screen provides a clear message and an action for creating the user's
first task.

![TaskFlow Empty Task State](images/wireframes/empty-dashboard.png)

---

# 5. Task Management Screens

## 5.1 Create Task

The create task modal allows the user to create a new task.

The screen includes:

- Title
- Description
- Status
- Priority
- Start date
- Due date
- Category
- Create Task action

![TaskFlow Create Task Wireframe](images/wireframes/create-task.png)

## 5.2 Edit Task

The edit task modal allows the user to modify an existing task.

The screen includes the editable task information and an action for saving
the changes.

![TaskFlow Edit Task Wireframe](images/wireframes/edit-task.png)

## 5.3 Task Details

The task details page displays the complete information for a selected task.

The screen provides access to task editing and deletion.

![TaskFlow Task Details Wireframe](images/wireframes/task-details.png)

---

# 6. Category Management Screens

## 6.1 Category Management

The category management interface allows users to view and manage their
user-defined categories.

![TaskFlow Category Management Wireframe](images/wireframes/categories.png)

## 6.2 Create Category

The create category modal allows the user to create a new category.

The wireframes cover the primary screens required for the initial TaskFlow
